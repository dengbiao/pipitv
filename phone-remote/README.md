# PIPI 遥控助手

安装在安卓手机上的蓝牙鼠标与键盘助手，用于操作电视的 Android 设置页。
电视端无需安装 App，不依赖 ADB、Wi-Fi 服务或 Google Play 服务。

## 使用

1. 手机需要 Android 9 或以上，且系统支持 `BluetoothHidDevice`。
2. 安装 `outputs/PIPI-REMOTE-0.1.0.apk`，打开并点“开始配对”。
3. 允许附近设备权限、启用蓝牙、允许手机被发现。App 显示手机真实蓝牙名称。
4. 用电视原来的遥控器进入海信自己的蓝牙 / 外设设置，搜索这个手机名称并确认配对。
5. 若未自动连接，点“已配对的设备”，选电视；以 App 显示“已连接”为准。
6. 单指滑动移动光标，轻点左键，双指上下滚动，长按后移动可拖动。也提供独立的左右键、滚动、返回、Tab、确认按钮。
7. 操作电视“关于手机 → 版本号”七次，再进入“系统 → 高级 → 开发者选项 → USB 调试”。
8. 完成后点“结束连接”，服务会松开按键、断开连接并注销 HID。

蓝牙系统配对使用用户确认，应用不自动接受配对码。现有配对记录仅在用户手动选择后用于连接。
连接期间保留前台服务通知，退出到系统配对界面不会丢失 HID 注册；从最近任务中划掉 App 会停止服务。
不自动开机启动，不请求网络、文件、定位或无障碍权限。蓝牙连接是否可用取决于具体手机 ROM 和电视 HID 支持，需要实机验证。

## 构建与验证

```sh
python3 scripts/build_phone_remote.py
```

沿用项目缓存的官方 Android SDK 和 JDK，不使用 Gradle 或网络依赖。
构建会执行纯 Java 的手势和 HID 报告测试，检查签名、包名、最低版本及权限。
签名使用项目开发密钥，输出 `outputs/phone-remote-build.json`。

手机和 Mac 在同一 Wi-Fi 时，可运行下列只提供安装页、APK 和二维码的服务：

```sh
python3 scripts/serve_phone_remote.py --bind 192.168.1.11 --port 4175
```

手机打开 `http://192.168.1.11:4175/`。如果 Mac 的 Wi-Fi 地址发生变化，替换 `--bind` 和访问地址。
已生成的二维码位于 `outputs/phone-remote-install-qr.png`。

## 当前验证边界

已进行的自动化检查见构建报告。手机与电视之间的蓝牙配对、指针移动、点击和滚动尚需用户设备验证，不能以 APK 编译成功替代实机连接成功。
