# 百度网盘文件夹

家长空间 → 内容入口 → 百度网盘 → 扫码连接。用手机授权「皮皮课堂」后，选择 `/我的应用数据/皮皮课堂` 内的内容文件夹，确认「使用此文件夹」。用户可见路径对应开放 API 的 `/apps/皮皮课堂`，电视复用原项目的百度应用，通过原 Token Broker 完成换票。

内容入口按「本地内容 / 百度网盘」切换，下方仅显示当前来源的系列。右侧按钮随来源变化；本地扫描路径和网盘选择的文件夹分别保存。页面不再显示静态介绍、汇总计数或独立的网盘大卡片。误加的系列可点「删除」；「整理入口」可批量清理已不在当前同步/扫描范围内的旧入口，也可恢复已删除入口。删除不操作原文件，重扫和重连也不会自动恢复；观看记录与统计保留。离线、未接入的 U 盘不会仅因离线被批量清理。

选中的目录若直接包含媒体文件，作为一个系列；否则各个有媒体内容的第一层子目录分别成为系列，继续递归读取其中的子目录。空目录、隐藏文件及不支持格式会跳过。可以更新目录、重选文件夹，并沿用内容入口的改名、语言和屏蔽设置。新发现的网盘系列不会仅凭名称自动匹配英语游戏题库。

## 播放与数据

- 网盘目录独立于本地/U 盘扫描。仅完整成功的同步会替换索引；中断、分页异常、权限或网络错误保留前一份目录。
- 系列与文件用账号命名空间和 `fs_id` 构造稳定标识；更改显示文件名、缩小或扩大同系列的同步范围、下载链接刷新均不清除续播。跨系列移动文件仍按新系列处理。
- 网盘视频在播放菜单选择「流畅 480P / 高清 720P / 原画」，默认尝试 480P，成功的手动选择会记住。前两者请求百度 `streaming` 的 `M3U8_AUTO_*` HLS 流并使用 `xpanvideo;…;ts` 请求头；原画及音频每次重新获取短期 `dlink`，使用 `User-Agent: pan.baidu.com`。切换保留当前进度、暂停状态、队列与家长预算；转码不可用会提示并恢复可播放来源。HLS 清单及其地址仅驻留原生内存，不写入目录缓存或 React。1080P 转码在本次真实视频上被百度拒绝，菜单不提供该档；原画仍可为 1080P。
- 百度转码返回需要广告等待（133）时，自动取消这次转码尝试，改用正常授权的原画文件来源；不再显示广告倒计时，也不发送会退出播放器的返回键。实际来源显示为「原画」，保留原先的清晰度偏好；原画也不可用时显示播放错误。此行为没有伪造广告完成或播放票据，原画的起播速度仍受下载链路影响。
- 切换时先静音恢复目标画面；若电视将 HLS 定位到前一个分段，则继续解码到原进度，再恢复暂停或播放。设备支持时加速这段衔接，预览帧不计入观看统计；后台暂停会停止衔接，返回后继续。
- 首帧同时核对实际纹理更新，兼容部分电视缺失的开始渲染通知；未确认画面或仍在定位时的结束回调不能记为已看完，也不会自动切到下一集。
- 480P/720P 是请求的转码上限，实际尺寸受原文件限制。原片只有 480P 时，选择 720P 不会增加原片细节；诊断与验收记录实际解码尺寸。
- 沿用记忆/顺序/随机播放、实际播放统计和家长时长规则。起播和拖动性能取决于百度接口、网络及电视编码支持；转码权限、文件转码状态也会影响可选清晰度。播放菜单显示实际缓冲状态，原生诊断只输出解码尺寸与缓冲计数，不输出播放地址。
- 封面优先使用最近播放文件的百度缩略图。图片和 PDF 先下载到应用缓存再打开，单文件上限 32 MiB。首版没有整系列离线下载或视频断网播放。
- Access/Refresh Token 以 Android Keystore AES-GCM 加密写入禁止备份区域；React、APK 素材、目录缓存与诊断输出均不含凭据或签名下载链接。更新凭据为单次刷新，响应不明时重新授权。
- 断开连接清除电视上的凭据与网盘目录/图片缓存，隐藏网盘入口，保留观看记录、家长 PIN、时间设置、U 盘资源和电视应用选择。同账号重新连接和同步后，可恢复原入口记录。

## 授权服务

复用 `https://oauth.dreamcanvas.site`，原服务位于火山北京实例 `openclaw`（公网 `115.190.248.212`）。本次仅更新 `pipi-broker-broker-1`，保留原应用坐标、Nginx、私有网络、非 root/只读容器设置及服务器 SecretKey 文件。

| 接口 | 请求 | 用途 |
| --- | --- | --- |
| `POST /oauth/device/code` | `{}` | 返回百度设备码、用户码、二维码和有效期；应用和 scope 固定在服务器 |
| `POST /oauth/token` | `{"grant_type":"device_token","code":"…"}` | 按返回 interval 轮询扫码结果，最低 10 秒 |
| `POST /oauth/token` | 原授权码、刷新请求 | 保持旧手机客户端兼容 |

源码位于 `services/baidu-token-broker/`，从 `dengbiao/xuanli-ai-website` 的原服务扩展。原授权码/刷新与 Node 适配器测试全部保留，新增设备码测试。`/readyz` 只表示部署和配置就绪，不代表用户已授权。

```sh
npm --prefix services/baidu-token-broker ci
npm --prefix services/baidu-token-broker test
python3 scripts/deploy_baidu_broker.py --key '/absolute/path/to/private-key.pem' --apply
```

部署脚本使用旧容器已有的应用坐标和 Secret 文件挂载，不复制 SecretKey；生成独立版本目录和镜像，失败恢复旧版本。版本与回滚坐标见 `outputs/qa/baidu-netdisk-20261101/broker-deployment.json`。新接口的 Mac 和电视真实 HTTPS/二维码探测结果与账号授权结果分别记录。

## 验证

```sh
npm test
npm --prefix web run test:sites
python3 scripts/build_android.py
python3 scripts/verify_baidu_tv.py
```

`verify_baidu_tv.py` 只重建和清理 `com.pipi.kids.baiduqa`。测试账号、模拟目录与 PIN 仅存在该独立包；不读取或重设正式应用 PIN。它验证目录分页、账号隔离、同步失败回退、改名/范围变更后的续播、加密保存、重连与本地数据保留，并从电视实际请求线上二维码（不进行账号授权）。测试应用需在验证完成后卸载。

浏览器界面夹具位于 `web/baidu-preview.html`，仅端口 4197 可用，使用模拟授权；不会打进正式 APK。入口整理夹具是 `web/cleanup-preview.html`，仅端口 4198 可用。正常网页预览明确提示在电视操作，不收集网盘凭据。真实账号由家长扫码连接；目录与播放验收须使用已授权账号的实际内容，不能用模拟夹具替代。本轮更新与真机证据位于 `outputs/qa/baidu-quality-cleanup-20261101/`。

官方依据：[设备码授权](https://pan.baidu.com/union/doc/使用入门/接入授权/设备码模式授权/)、[目录权限](https://pan.baidu.com/union/doc/使用入门/权限与配额/)、[下载与请求头](https://pan.baidu.com/union/doc/基础网盘服务/下载/)。

转码依据：[百度视频播放 FAQ](https://pan.baidu.com/union/doc/faq/视频播放/)。实际清晰度仍须在已授权账号和当前文件上验证，不能用模拟清单代替真实播放验收。
