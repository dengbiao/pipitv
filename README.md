# PIPI KIDS

奶油白大卡片电视桌面。首页媒体入口从家长指定的电视存储、U 盘或百度网盘文件夹自动整理；支持视频、音频、图片和 PDF 绘本，也可由家长添加已安装的电视应用。内容由家长提供，不包含在线课程或影片资源。

## 当前能力

- 家长空间「内容入口 → 百度网盘」支持手机扫码授权，在「我的应用数据／皮皮课堂」中选择一个文件夹并同步成首页系列。支持子目录、在线点播、续播和原有三种播放模式；播放菜单可选择流畅 480P、高清 720P 或原画，默认尝试 480P。目录与封面缓存保存在电视，断开连接保留观看记录。授权服务已部署，已在家长连接的真实账号上验证目录、原画和 480P/720P 转码播放。见 [网盘接入](docs/baidu-netdisk.md)。
- 遥控器方向键选择，确认键打开，返回键回到上一级；超过三张卡片时横向滚动。
- 家长 PIN 管理扫描路径、入口名称、中文说明、内容语言和显示状态。支持多个扫描路径，父子路径自动去重；首次默认当前 U 盘根目录。新增内容自动出现，系统、缓存、隐藏和空目录自动跳过。取消扫描或断开存储时暂不展示，重新连接保留改名、屏蔽和观看记录。误加入口可删除；「整理入口」可批量清理旧范围的入口或恢复已删除入口，原文件与观看记录保留，重扫不会自动恢复删除项。入口不支持手动新建或改指向；封面跟随实际媒体更新。见 [内容自动整理](docs/content-library.md)。
- 电视上的入口名称和中文说明使用已安装的系统输入法，支持遥控器及输入法自身的中文输入；返回先收起键盘，再取消编辑。浏览器使用普通文本输入框。家长 PIN 继续使用四位屏幕数字键盘。
- 家长空间「电视应用」可分别设置「添加到首页」和「加入管控」，按 OK 自动保存。加入管控的应用与桌面内容共用每日上限、单次上限、休息间隔和可用时段；按屏幕开启时的前台使用时间累计，到时返回休息页，切换受控应用不会重置预算。未加入管控的应用不限时，不消耗共享额度，也可在休息时间打开。现有应用默认不加入管控。跨应用管控需在电视系统中由家长开启「PIPI 应用管控」辅助服务；未授权会明确显示待生效。该服务仅接收应用包名相关窗口事件，不读取页面、输入、截图或按键。播放统计仍独立统计桌面内容。首页保留真实图标；卸载/停用的应用暂时隐藏，重装后恢复，首页选择与管控选择均保留。浏览器仅支持界面预览。
- 单次时长、每日额度、休息间隔和可用时段；家长确认选项后自动保存，无需再点保存按钮，关闭再打开不会重置当天记录。
- 到时进入休息页并朗读页面上的短提示，每个本地日期自动轮换一句；31 句均不超过 15 字（含标点），同一天保持一致。提示音使用 Dreamina CLI 生成的「暖心学姐」女声（用户选定的 A 版），语气轻快清晰。语音随应用打包，电视无需联网或安装朗读引擎；退出休息页或应用时停止播报。
- 电视版在应用内播放，并由原生计时规则到时停止播放。已启用辅助服务时，加入管控的应用也沿用整体规则；未加入管控的应用和其他信号源不属于全电视锁定。调试不限时状态继续作用于共享管控，原有设置与用时不重置。
- 视频和图片直接全屏显示。普通视频按原始比例完整居中显示，必要时留黑边；仅对按文件名和大小核对的「古力小超人 01 Hello.mp4」自动隐藏顶部录屏计时条，等比裁剪、不拉伸、不修改原文件。旧的逐视频裁剪选择不再生效。视频/音频按 OK 只切换播放与暂停并显示简洁进度条，左右键快退/快进 10 秒；菜单键（或下方向键）打开「选集」，不再提供「画面」按钮。选集在右侧展示当前系列的真实缩略图、标题、主题和时长，上下预览、OK 播放，浏览时不会自动收起。返回键依次收起选集栏和菜单，再回内容列表；播放中的底部面板 5 秒无操作自动隐藏，暂停时保留进度条。见 [播放器交互](docs/player-controls.md)。
- 系列列表提供「记忆播放 / 顺序播放 / 随机播放」，默认记忆播放，逐系列保存选择。记忆播放优先到期复习，继续新内容和同日重播；随机播放在当前系列内每轮不重复，全部播完后重新随机，退出或重启保留本轮进度，两者均持续到家长限时；顺序播放到最后一集时显示完成页。三种模式均优先恢复未完成内容。播放菜单支持侧栏手动选集，切集不重置已用时长，到限时停止；完成页可重播或选集，不会自动消失成黑屏。
- 首页每个系列封面右上角显示只读的累计播放时长；家长空间的「播放统计」展示各系列视频/音频时长、所有英语视频总时长，并可逐系列确认清零。按实际播放累计，重复播放计入，暂停、缓冲、后台、浏览和跳转进度不计入；从本功能启用或最近清零起统计，重启后保留。清零不影响续播、复习和每日额度。英语合计按入口编辑中的「内容语言」汇总视频，随系列清零同步更新。
- 首页系列标题右侧的「进入」直接打开系列列表，封面继续用于直接续播；副标题旁低调的 `Play Games` 进入本系列的 `Listen & Find` 英语小游戏，列表页不再显示游戏按钮。返回后恢复对应入口的遥控器焦点。测试阶段默认 0 遍即可进入，也可设置完整播放若干遍后解锁。家长空间「系列游戏」可逐系列设置 0–5 遍并预览。古力、WOW 各有 20 道按实际视频台词整理的题目，提供英文语音、三图选择、遥控器操作和离线资源；答错明确播报 “You are wrong. This is …”，答对反馈播完后自动切题。见 [游戏说明](docs/series-games.md)。
- 内置三组示例图片，仅在其目录参与扫描时显示并标明「示例内容」。在家长空间选择真实内容的扫描路径即可自动生成入口。

当前这台电视已配置 U 盘上的两个实际文件夹：古力小超人、WOW English。WOW 第1～4周的资源已按用户要求合并到 `Wow第1季学习打卡` 总目录。配置见 `android/assets/device-content.json`；现有安装通过 `android/assets/resource-relocations.json` 一次性更新旧入口、播放记录和续播位置，保留家长 PIN 与计时设置。
入口可自动从内容取封面：尚未播放时取第一个媒体文件，之后取该入口最近成功播放的文件；视频取帧会跳过黑场，缩略图只缓存在应用内部。修改入口名称或样式不会清除仍属于该入口的播放记录。

## 开发预览

```sh
npm --prefix web install
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

打开 http://localhost:4173/ 。浏览器预览会把导入的文件保存在本机 IndexedDB；电视安装版直接读取电视和 U 盘。首次进入家长空间自行设置 PIN。

## Android 安装包

本机已准备官方 Corretto 17、Android Platform 35、Build Tools 35 和 ADB，缓存位于 `~/.cache/pipitv-tools/`。从干净的 Apple Silicon Mac 重建：

```sh
python3 scripts/prepare_android.py
npm --prefix web install
python3 scripts/build_android.py
```

产物：`outputs/PIPI-KIDS-0.1.0-dev.apk`。构建不依赖 Android Studio/Gradle。当前是本地侧载开发版，最低 API 21、target API 28；界面包含旧 WebView 的兼容构建，但具体电视、文件权限和媒体编码仍需真机验证。新系统的存储隔离/旧 WebView 可能需要后续设备适配，不作为商店发布版本。

开发签名密钥存于 `~/.cache/pipitv-tools/pipikids-development.keystore`，请保留以便覆盖更新；不要将密钥提交到仓库。应用关闭云备份，PIN 使用带随机盐的 PBKDF2，本应用没有写入或删除原始媒体文件的能力。

## 连接这台海信电视

已连接：`192.168.1.5:5555`，海信 `VIDAA_TV`，Android 11 / API 30。2026-11-01 由用户在电视打开 USB 调试并确认 RSA 授权后，已完成安装和真机启动。当前不改变海信的默认 HOME。

电视打开并授权 ADB 后：

```sh
python3 scripts/install_tv.py --device 192.168.1.5:5555
```

脚本先保存设备信息和原 HOME 查询结果，再安装并打开 PIPI KIDS，保存前台证据和截图。脚本不会更换默认 HOME、停用原桌面、重置电视或刷写固件。默认桌面应在真机确认可用后再选择，海信固件是否接管 Home 需单独验证。

也可启动仅提供 APK 和安装页的局域网服务：

```sh
python3 scripts/serve_install.py --bind 192.168.1.11 --port 4174
```

电视能否通过 U 盘安装第三方 APK，由电视型号和固件决定。服务只读取公开安装包、logo 和安装页，不提供项目文件或网络扫描报告。

## 手机蓝牙遥控助手

`phone-remote/` 是安装在安卓手机上的独立应用，供电视隐藏设置页需要鼠标时使用。
支持触摸板、左右键、滚动、返回、Tab 和确认；电视端无需先安装应用。最低 Android 9，具体手机与电视的蓝牙 HID 兼容性需要实机确认。

```sh
python3 scripts/build_phone_remote.py
python3 scripts/serve_phone_remote.py --bind 192.168.1.11 --port 4175
```

手机访问 `http://192.168.1.11:4175/` 下载 `outputs/PIPI-REMOTE-0.1.0.apk`。
配对步骤与许可说明见 [phone-remote/README.md](phone-remote/README.md)。

## 验证

电视调试时可临时暂停时长、休息与可用时段拦截：`python3 scripts/debug_time_limits.py pause`。
原家长设置与每日用时保持不变，调试播放仍正常累计播放统计。状态保存在 `outputs/debug-time-limits-state.json`；
调试结束执行 `python3 scripts/debug_time_limits.py restore` 恢复原限制，或用 `status` 查看当前状态。
此操作使用同签名的临时辅助包，完成后自动卸载，不新增对网页开放的开关。

```sh
npm test
python3 scripts/build_android.py
```

浏览器流程、计时验证和对照截图记录在 `outputs/qa/`，视觉检查见 `design-qa.md`。Android 时间策略测试与 APK 签名验证属于构建步骤；真机安装与播放在获得调试连接后验证。

最新真机结果见 `outputs/tv-acceptance.json`：安装包哈希回读、U 盘视频播放、各入口的最近播放记录，以及应用重启后的保留检查。首页最新截图为 `outputs/qa/tv-layout-final.png`。物理 U 盘拔插和全部视频编码的兼容性不属于此次抽样检查。
